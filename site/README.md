# Сайт керамической мастерской

Одна страница: посуда в наличии, работы (подборки фото), розыгрыш, как получить, контакты.
Всё содержимое редактируется онлайн в админке Pages CMS, программировать не нужно.

## Как заполнить сайт

1. Откройте [app.pagescms.org](https://app.pagescms.org), войдите через GitHub и выберите репозиторий.
2. **Сайт**: название, контакты, главное фото, фон. Тексты «Оплата», «Упаковка», «Уход» и «О себе» заполняйте только тем, за что ручаетесь. Пустые поля на сайте не видны.
3. **Посуда**: по вещи на запись. Фото, цена, статус, размер. Проданное ставьте в «Продано» — уйдёт в конец списка. «Скрыть с сайта» убирает вещь, не удаляя её.
4. **Работы**: подборки. Загрузите фото пачкой и перетащите лучшие наверх: первые пять попадут на главную. Подпишите нужные фото в «Подписях»: подписанное фото показывается крупно, подпись стоит рядом.
5. **Розыгрыши**: даты начала и итогов сами переключают статус. После итогов впишите победителя.
6. Когда всё заполнено, в разделе «Сайт» выключите «Показывать примеры».

Каждое сохранение в админке — это коммит в GitHub. После него сайт пересобирается сам, за пару минут.

## Как снимать

- Один и тот же матовый светлый фон: бумага, картон, лён. Тон фона сайта подбирается под него в разделе «Сайт».
- Мягкий свет сбоку от окна, без вспышки.
- Вещи для магазина — вертикально, одна вещь в кадре, по центру. Кружки и миски — чуть сверху, тарелки — сверху.
- Второе фото — вещь в руке: так видно размер. На сайте оно появляется при наведении.
- Главное фото — горизонтальное.

Фото прямо с телефона подходят: при публикации они уменьшаются до 2000 px, из них удаляются геоданные, и для сайта делаются лёгкие копии.

## Публикация (GitHub Pages)

Workflow `.github/workflows/pages.yml` собирает и публикует сайт при каждом изменении в ветке `main`.

1. GitHub → Settings → Pages → Source: **GitHub Actions**.
2. Слейте ветку с сайтом в `main` или запустите workflow вручную во вкладке Actions.

Сейчас сайт лежит в репозитории мода `my-gd-mod`, поэтому адрес будет вида `…github.io/my-gd-mod/`. Лучше перенести `site/`, `tools/`, `.pages.yml` и workflow в отдельный репозиторий или подключить свой домен.

## Посмотреть у себя

```bash
npx http-server site -p 8080          # без обработки фото
# или как на GitHub Pages:
npm install --no-save sharp && node tools/build-site.mjs && npx http-server _site -p 8080
```

## Файлы

| Файл | Что внутри |
|---|---|
| `content/site.json` | название, контакты, главное фото, способы получения, тексты |
| `content/products.json` | вещи |
| `content/portfolio.json` | подборки и подписи |
| `content/giveaways.json` | розыгрыши |
| `photos/` | загруженные фото |
| `index.html`, `styles.css`, `app.js` | страница |
| `../tools/build-site.mjs` | сборка: обработка фото, `photos.json`, превью ссылки |
