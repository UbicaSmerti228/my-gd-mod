# Сайт керамической мастерской

Статический сайт без сборки: HTML, CSS и JavaScript. Наличие, цены, доставка, портфолио и розыгрыши лежат в JSON-файлах и редактируются онлайн через бесплатную админку Pages CMS.

Разбор типовых решений ИИ, концепция и чек-лист проверки — в [CHECKLIST.md](CHECKLIST.md).

## Что где лежит

| Файл | Что внутри | Кто правит |
|---|---|---|
| `content/shop.json` | Контакты, доставка и самовывоз, текущий и следующий обжиг, формы посуды, остатки по глазурям, журнал обжигов | Вы, через админку |
| `content/portfolio.json` | Подборки портфолио: название, тип, описание, фото с подписями | Вы, через админку |
| `content/giveaways.json` | Розыгрыши: приз, даты, условия, победитель | Вы, через админку |
| `photos/` | Загруженные фото. `photos/demo/` — нарисованные примеры, их можно удалить | Админка загружает сюда |
| `data.js` | Цвета глазурей, профили форм для чертежей, этапы работы, расчёт для кафе | Разработчик |
| `draw.js` | Рисует чертежи, печь и тестовые плитки | Разработчик |
| `app.js` | Логика страницы | Разработчик |

## Как править онлайн (Pages CMS)

1. Откройте [app.pagescms.org](https://app.pagescms.org) и войдите через GitHub.
2. Выберите репозиторий и ветку, где лежит сайт. Админка прочитает файл `.pages.yml` в корне репозитория.
3. Слева три раздела:
   - **Портфолио.** Добавьте подборку, выберите тип (серия, открытие печи, для кафе, мастерская), загрузите фото и подпишите каждое. Порядок фото перетаскивается. Если фото много и подписывать некогда, загрузите их пачкой в поле «Быстрая загрузка»: они встанут после подписанных.
   - **Розыгрыши.** Новый розыгрыш поставьте первым. Даты начала и итогов управляют статусом сами: до начала — «скоро», между датами — «идёт», после — уходит в архив. После итогов впишите победителя.
   - **Наличие, обжиги и доставка.** После продажи уменьшите остаток в нужной глазури. После нового обжига поменяйте номер и даты, добавьте строку в журнал.
4. Нажмите «Save». Админка сохранит изменения коммитом в GitHub, и сайт обновится после публикации.

Новая форма посуды без своего чертежа рисуется по шаблону своего типа (кружка, миска, тарелка, молочник) с указанными диаметром и высотой.

## Как посмотреть на своём компьютере

Сайт загружает данные из `content/*.json`, поэтому открыть `index.html` двойным щелчком не получится. Запустите локальный сервер из корня репозитория:

```bash
npx http-server site -p 8080
```

и откройте http://localhost:8080.

## Как опубликовать (GitHub Pages)

В репозитории есть workflow `.github/workflows/pages.yml`. Он публикует папку `site/` при каждом изменении в ветке `main`.

1. GitHub → репозиторий → **Settings → Pages → Source: GitHub Actions**.
2. Слейте ветку с сайтом в `main` (или запустите workflow вручную во вкладке Actions).
3. Адрес появится в **Settings → Pages**.

Сейчас сайт лежит в репозитории мода `my-gd-mod`, поэтому адрес будет вида `…github.io/my-gd-mod/`. Лучше перенести папку `site/`, файл `.pages.yml` и workflow в отдельный репозиторий — тогда адрес будет понятнее и сборка мода не будет запускаться от правок сайта.

```bash
node tools/demo-photos.mjs
```
