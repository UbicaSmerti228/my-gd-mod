# Как обычно делает сайты ИИ — и что сделано здесь вместо этого

## 1. Типовые решения ИИ (то, чего на сайте нет)

**Структура — один и тот же шаблон для любого бизнеса**
- Первый экран по центру: огромный заголовок, подзаголовок и две одинаковые кнопки «Купить» / «Узнать больше». Высота ровно 100vh.
- Три карточки «преимуществ» с иконками в кружочках: «Ручная работа», «Натуральные материалы», «Быстрая доставка».
- Карусель отзывов с пятью звёздами и выдуманными именами.
- Блок счётчиков: «500+ довольных клиентов», «10 лет опыта».
- Подписка на рассылку «Получите скидку 10%».
- Подвал в четыре колонки ссылок и иконки соцсетей.
- Порядок секций не зависит от того, что продаётся.

**Визуал — «красиво», но мыльно**
- Стоковые фото с Unsplash, часто вообще не той посуды.
- Кремовый фон #F4F1EA, терракотовый акцент, Playfair Display или Cormorant для заголовков и Inter для текста — самый частый «тёплый» набор ИИ.
- Одинаковые карточки: скругление `rounded-2xl` и мягкая тень на каждом блоке.
- Градиентные пятна, стекло (glassmorphism), шум поверх всей страницы, волнистые разделители.
- Эмодзи как маркеры разделов, номера «01 / 02 / 03» там, где нет последовательности.
- Всё выровнено по центру.

**Движение**
- Каждый блок «всплывает» при прокрутке (fade-in-up), до этого он невидим.
- Увеличение `scale(1.05)` при наведении на всё подряд, бегущая строка, параллакс.

**Тексты — без фактов**
- «Создано с любовью», «Вдохновлено природой», «Уникальная ручная работа», «Поднимите сервировку на новый уровень».
- Нет размеров, объёма, веса, состава, ухода, сроков, условий доставки и боя.
- Отзывы и цифры придуманы.

**Магазин — витрина без пути**
- Карточка: фото, название, цена, «В корзину». Нет остатков, нет сведений, что предметы ручной работы отличаются.
- Корзина ведёт в никуда: оплаты нет, а пользователь об этом не знает.

**Техника**
- Нет фокуса для клавиатуры, кнопки сделаны из `div`, нет `alt`, бежевый текст на бежевом ниже нормы контраста.
- Одна контрольная ширина экрана, на телефоне всё разъезжается.
- Контент нельзя обновить без программиста.

## 2. Концепция этого сайта

Небольшая мастерская живёт ритмом печи: посуда появляется партиями после каждого обжига. Сайт построен вокруг этого ритма, а не вокруг шаблона лендинга.

| Вместо шаблона | Что сделано | Зачем покупателю |
|---|---|---|
| Hero по центру с двумя кнопками | Разрез печи после обжига: предметы стоят на полках в одном масштабе. Закрашенные — есть в наличии, пунктир — проданы. Конусы-свидетели показывают, что печь дошла до 1230 °C | Сразу видно, что есть, чего нет и какого всё размера |
| Стоковые фото в карточках | Чертёж каждой формы, как в археологии: слева вид снаружи в цвете глазури, справа разрез стенки, размеры и масштабная линейка | Видно толщину стенки, форму дна и размер, а не только «красиво» |
| «Ручная работа» с иконкой | Строка «±3 мм: всё точится на круге вручную, предметы одной формы немного отличаются» | Честное ожидание вместо лозунга |
| Палитра «крем + терракота» | Цвета страницы взяты из глазурей: «Топлёное молоко», «Овсянка», «Пепел», «Жжёный сахар», «Ржаная корка». Красноватый цвет только у живых данных печи — даты и остатки | Цвет несёт смысл, а бежевый остаётся главным |
| Три карточки преимуществ | Тестовые плитки глазурей: где глазурь истончается, где собирается, матовая или глянцевая, остаются ли следы от ножа | Помогает выбрать глазурь под свою еду и привычки |
| Карусель отзывов | Журнал обжигов: сколько предметов было в печи, сколько ушло в брак и почему | Доверие через факты, а не через звёздочки |
| «Скоро в продаже» | Следующий обжиг: даты, свободные места на предзаказ по каждой форме | Понятно, когда ждать и успеешь ли |
| Иконки «Этапы работы» 01-02-03 | Шкала «19 дней от глины до коробки»: каждый этап на общей шкале дней, цвет полосы — цвет глины на этом этапе | Объясняет цену и сроки |
| FAQ-аккордеон | Вкладыш, который лежит в коробке: можно / осторожно / нельзя | Сразу видно, что посуда переживёт посудомойку |
| Корзина-заглушка | Заказ составляет готовую заявку с доставкой (OZON, Авито, самовывоз) и честно говорит: «Это ещё не оплата» | Нет ложного ощущения, что заказ уже оплачен |
| Галерея-сетка с обрезанными фото | Портфолио подборками: серии, открытия печи, заказы для кафе, мастерская. Внутри — ровные строки без обрезки, подписи, просмотр по одному с листанием | Даже 50 фото в подборке выглядят аккуратно |

Шрифты: Piazzolla для заголовков, Golos Text для текста, IBM Plex Mono для размеров и дат. Все три поддерживают кириллицу и не входят в набор «по умолчанию» у ИИ.

## 3. Чек-лист с результатами проверки

Проверено в Chromium на ширине 1440 и 390 px.

**Смысл**
- [x] Первый экран отвечает на вопросы «что продают», «что есть сейчас», «когда будет ещё».
- [x] У каждой формы есть объём, диаметр, высота, вес, глазурь, остаток по каждой глазури и цена.
- [x] Указано, что предметы ручной работы отличаются (±3 мм, подтёки глазури).
- [x] Есть уход: посудомойка, микроволновка, духовка, что нельзя.
- [x] Доставка с ценой и сроком: OZON 350 ₽ и 5–10 дней, Авито 250–600 ₽ и 7–10 дней, самовывоз — Иркутск, ул. Пискунова, 156/1, по договорённости.
- [x] Заказ не притворяется оплатой и говорит, что будет дальше.
- [x] Розыгрыш: приз, сроки, условия по шагам, как выбирается победитель, архив с итогами.
- [x] Нумерация используется только там, где есть настоящая последовательность: этапы работы и шаги розыгрыша.
- [x] Нет выдуманных отзывов, счётчиков «500+» и рассылки со скидкой.

**Внешний вид**
- [x] Нет стоковых фото: чертежи и демо-снимки нарисованы из тех же профилей форм.
- [x] Нет градиентных пятен, стекла, эмодзи и одинаковых скруглённых карточек с тенью.
- [x] Текст выровнен по левому краю, длина строк — около 60–70 знаков.
- [x] Одна анимация со смыслом: при загрузке печь «остывает». С включённой настройкой «уменьшить движение» анимации нет.
- [x] Всё содержимое видно без прокрутки-триггеров: ничего не спрятано за «появлением при скролле».
- [x] Портфолио с разными пропорциями фото раскладывается ровными строками без обрезки.

**Техника**
- [x] Нет горизонтальной прокрутки на 390 px и 1440 px.
- [x] Нет ошибок в консоли.
- [x] Все кнопки — `<button>`, у фокуса видимая обводка, окна закрываются по Esc и по клику на фон.
- [x] В просмотре фото работают стрелки на клавиатуре и свайп.
- [x] Контраст вторичного текста 5,5:1, акцентного (даты, остатки) — 5,2:1. Это выше нормы AA (4,5:1).
- [x] Заказ и настройки фильтров сохраняются в браузере, при ошибке хранилища сайт работает дальше.
- [x] Наличие, цены, обжиги, доставка, портфолио и розыгрыши редактируются онлайн через Pages CMS, без кода.

## 4. Этапы

**Этап 1 — готово.** Сайт целиком: печь, наличие с чертежами, портфолио, глазури, журнал обжигов, предзаказ, процесс, розыгрыш, доставка и уход, заказы для кафе, онлайн-админка.

**Этап 2 — нужно от вас.**
- Название мастерской (сейчас «Шамот» — это заглушка), контакты, Telegram.
- Свои фото: по 5–15 на подборку. Снимайте при дневном свете на одном фоне; для масштаба хорошо, если в кадре есть рука.
- Свои формы, глазури, цены, остатки, даты обжигов. Если у вас нет журнала обжигов или ритма «раз в три недели», эти разделы можно переписать или убрать.
- Условия, которые я предложил сам и которые нужно проверить: бой за счёт мастерской, предоплата 50% за предзаказ, оплата по СБП, упаковка «коробка в коробке».

**Этап 3 — по желанию.**
- Заявки сразу в Telegram через бота, без копирования текста.
- Онлайн-оплата (ЮKassa или Т-Касса).
- Отдельные страницы товаров для поиска Яндекса и Google, превью ссылок для соцсетей.
- Свой домен.
